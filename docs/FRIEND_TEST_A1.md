插件 ZIP 本身不包含宿主补丁。搭环境的人须先核对这一项，再交朋友测试；本次验收没有替朋友安装或修改其设备。

## 先跑一个可观察的正常样例

所有管理操作在私聊中进行。管理员与朋友应处于同一测试人格。

管理员：

```text
/xp admin switch on
/xp admin template set 语气风格 喜欢 双向 2
```

朋友：

```text
/xp help
/xp on
/xp set 语气风格 喜欢 双向 2
/xp show
/xp status
```

双方都设置后，围绕“语气风格”聊同一个简单问题，记录回复。分别改为强度1和4、主动和接受，对同一问题做几次对照。偏好是提示指导，不把模型每次措辞完全一致作为通过标准。

## 实测表

| 项目 | 操作 | 应观察到的结果 |
|---|---|---|
| 本人管理 | 设置、查看、修改、删除一条合成标签 | 命令准确处理本人档案，不进入闲聊回答 |
| 双方边界 | 同一标签一方喜欢、另一方禁止 | 更严格限制生效，不能因喜欢继续推进 |
| 单方未设置 | 只给一方设置标签 | 不把未设置当作同意 |
| 关闭 | `/xp off` 后继续相关话题 | 后续请求停止读取/注入本插件偏好 |
| 清空 | `/xp clear`，按机器人返回的一次性确认码确认，再 `/xp show` | 本人档案清空；不要使用文档里的虚构确认码 |
| 管理员关闭 | 管理员 `/xp admin switch off` | 各用户后续请求都停止偏好注入 |
| 群聊隔离 | 私聊保存合成标签后，在测试群执行查看/相关聊天 | 不显示私人标签、状态或私聊原文；只给通用引导 |
| 用户/人格隔离 | 第二个测试用户、另一个测试人格分别查看 | 看不到第一个主体的档案 |
| 关系联动 | 装有固定版本 Relation Arc 时，使用其已有入口暂停关系/降低节奏 | 偏好不突破关系限制 |
| 普通话题 | 问天气、代码或日程等无关问题 | 不被无关偏好带偏 |
| 重启与停用 | 重启测试实例；停用插件后继续聊天 | 本人数据按设计保留；停用后不再产生插件指导 |

已发出的请求无法撤回；关闭/清空也不会代删模型已经收到的内容、宿主旧历史或既有备份。验证时以关闭后的新请求为基本观察点，在途窗口以本地已通过的专项证据为基础。
