# astrbot_plugin_preference_profile

AstrBot 独立插件：角色偏好与互动边界（XP 管理）首版。

**当前状态：开发中（P0 完成）**。功能、验收与兼容性说明将在 P7 完整化；
进行中的设计决策见 [docs/ADR.md](docs/ADR.md)，进度见 [docs/STATUS.md](docs/STATUS.md)。

要点（详见 ADR）：

- 私聊使用；管理员总开关默认关闭，用户需 `/xp on` 本人开启。
- Bot 人格模板与用户档案分离；普通用户仅能管理自己的档案。
- 喜欢/中立/不喜欢/明确禁止、主动/接受方向、强度与节奏独立建模；
  未设置不等于同意，单方喜欢不覆盖另一方禁止。
- 偏好私聊轮次在 Context Bridge 捕获前排除，不进入跨会话共享历史。
- Relation Arc 状态只读联动；关系暂停优先于偏好强度。
- 关闭/删除即时生效，慢请求不能复活；删除边界如实告知。
